# Créditos

Dados dos filmes (título, ano, sinopse, elenco, gêneros e pôsteres) vêm da API do [TMDB](https://www.themoviedb.org/). Este produto usa a API do TMDB, mas não é endossado nem certificado pelo TMDB.

Feito por Guilherme Araujo de Castro (Kirito).

Barbie é marca da Mattel. Este é um projeto de fã, sem qualquer ligação com a Mattel.
